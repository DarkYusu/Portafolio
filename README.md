# Portafolio de Antonio Badilla

Portafolio personal de Antonio Alejandro Badilla Espinoza, desarrollador Full-Stack con experiencia en Java, Python, JavaScript, Kotlin, Ruby on Rails y PHP.

El sitio presenta el perfil profesional, la formación tecnológica, las competencias, proyectos destacados y un caso de estudio basado en SpringEduManager.

## Ejecución local

No requiere instalación de dependencias ni servidor backend.

1. Clona o descarga el repositorio.
2. Abre `index.html` en un navegador web.
3. Para editar el proyecto, modifica `index.html`, `assets/css/style.css` o `assets/js/script.js`.

El sitio carga Bootstrap, Font Awesome, Chart.js y otros recursos mediante CDN, por lo que algunas funciones visuales requieren conexión a Internet.
